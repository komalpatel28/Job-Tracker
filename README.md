# Job Tracker

A Kanban-style board to track job applications across countries (Canada, Switzerland, UAE/KSA, South Korea, India).

## Features

- Add jobs with company, role, country, link and notes
- Drag and drop cards between Applied, Interview, Offer and Rejected
- Search by company or role
- Filter by country
- Data is saved in the browser using localStorage
- Responsive layout for mobile and desktop

## Built With

- HTML
- CSS
- JavaScript (no libraries)
